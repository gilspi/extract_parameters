# 🧪 Extract Parameters — GUI-инструмент для настройки SPICE-моделей
 
**Extract Parameters** — это Python-приложение с графическим интерфейсом, предназначенное для редактирования параметров SPICE-моделей (например, MEXTRAM), генерации `.osdi` файлов и запуска симуляций с помощью ngspice. Проект ориентирован на студентов и инженеров, работающих с полупроводниковыми моделями.

---

## 🚀 Возможности

- 📂 Загрузка и редактирование параметров из файлов `*.inc`, `*.va`
- 🖥️ Графический интерфейс для удобного изменения и просмотра параметров на разных языках (локализация)
- ⚙️ Автономная генерация `.osdi` файлов с помощью `openvaf`
- 🧪 Автономная симуляция через `ngspice`
- 📈 Визуализация результатов симуляции
- 📁 Управление файлами моделей и симуляций

---

## 🛠️ Установка (Ubuntu)

1. Клонируйте репозиторий:

```bash
git clone https://github.com/gilspi/extract_parameters.git
cd extract_parameters
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Убедитесь, что установлены `openvaf` и `ngspice`, и они доступны в переменной окружения `PATH`.

---

## 🖥️ Использование (Ubuntu)

1. Запустите графический интерфейс:

```bash
python main.py
```

2. В интерфейсе:
   - Выберите модель для симуляции.
   - Измените необходимые параметры.
   - Запустите симуляцию.
   - Просмотрите результаты симуляции на графическом пользовательском интерфейсе.
